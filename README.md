# KFB 금융사기 예방 백과사전 - 로컬 미리보기 (원본 common.js 적용)

- 원본 `common.js`를 `static/js/common.js`에 추가하고 jQuery 이후 로드합니다.
- `wiki.js`에 이전에 임시로 추가한 팝업 클릭/키보드 이벤트를 제거하여 중복을 방지했습니다.
- 원본 `common.js`의 팝업 종료 시 포커스 트랩 정리 순서만 로컬 복사본에서 수정했습니다.
- 원본 `common.js`가 먼저 로드되고, 이후 로컬 데모용 `getDevice`/`l_ajax`가 정의되어 서버 없는 화면 예시 데이터를 유지합니다.
- 실제 서버 API 콘텐츠가 아니라 로컬 시연용 예시 콘텐츠입니다.
- VS Code에서 폴더 전체를 열고 `wiki.html`을 Live Server로 실행하세요. jQuery/Swiper CDN 인터넷 연결이 필요합니다.
- 실제 브라우저에서 완전 검증하지 않았습니다. 원본 회사 파일과 Notion 페이지는 변경하지 않았습니다.

추가 수정: 슬라이드 이전/다음 버튼의 Swiper 기본 화살표 제거 및 위치 고정.
